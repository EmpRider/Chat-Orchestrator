STEP 1 / CONNECTION SETUP

Connect your tools

Configure the Ngrok tunnel, then use the local WebSocket URL in the extension and the MCP URL in your chat agent.

First-run setup

ONE TIME PER SELECTED BROWSER

1. Select installed Edge or Chrome below and choose Save & open browser. This uses a separate persistent Chat Orchestrator profile.

2. In that browser profile, select Install extension, choose Load unpacked and the bundled extension folder. Enter its local connection URL and profile key.

3. Once the extension shows Connected, verify that it belongs to the dedicated browser you just opened. This confirmation is required before the app may close managed browser windows.

4. Save the exact ChatGPT MCP connector name for this PC (for example PC1). The name must match the connector you create in ChatGPT and is included in all generated Agent instructions.
