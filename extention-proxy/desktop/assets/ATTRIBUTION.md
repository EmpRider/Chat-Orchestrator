# Desktop icon attribution

Icon artwork: [Icons8](https://icons8.com/).

The application and window/tray icon use the Icons8 Fluency **Network** icon:
https://img.icons8.com/fluency/256/network.png

The interface uses matching Icons8 iOS Filled icons bundled locally in PNG
format for offline use. Icon names are:
`server`, `puzzle`, `cloud`, `key`, `visible`, `hide`, `copy`,
`upload`, `link`, `play`, `shutdown`, `network`,
`minimize-window`, and `checkmark`.

Source URL format:
`https://img.icons8.com/ios-filled/48/BCC5D6/<icon-name>.png`

The `app.ico` Windows resource was generated from the same Icons8
`app.png` image. All assets are shipped with the app, so no icon network
requests are made at runtime. Attribution also appears in the desktop UI.
