## E2E-discovered implementation/test defects

1. Edge native tab grouping relocated a fresh worker/group into an unexpected window. The extension now checks group membership and returns only **exclusively owned** groups to the dedicated managed window. It never moves unrelated browser tabs. A regression case simulates the movement.
2. Fresh background tabs initially appeared as unsupported `about:blank` while navigating. `inspectChatTab` now gives **only newly created managed workers** a bounded opportunity for URL navigation; `start_prepared_worker` waits for readiness before checking the final site. No ambiguous prompt replay.
3. Chrome may delete a native tab group when its last worker tab closes. The recovery test was corrected to assert the newly recovered group's **root identity and window**, rather than require an obsolete numeric group ID to survive.
4. An older Tray Exit UI test expected the old black background, although current app uses the newer dark theme. The real UI assertion now checks the actual allowed dark palette and intact icons, without weakening the journal lock release assertion.
5. The isolated E2E launcher now requests a graceful shutdown of its own test Proxy before terminating the disposable Electron process, reducing test-profile stale-lock artifacts.

## Limitations / not proven

- `caller_tab_id` remains a routing hint, **not authentication** of a remote MCP caller; a caller with public MCP access may impersonate known tab IDs. This is an existing approved no-auth trust-boundary limitation, not solved by these tests.
- Chrome-specific browser behavior, real Claude/Gemini task-completion flows, public remote MCP tool invocation, packaged Windows distribution, and abrupt Windows power-loss replay were **not** independently exercised.
- A forcibly killed journal writer is intentionally left fail-closed; existing unknown-owner locks and UNCERTAIN event histories require manual verification/reconciliation.
- 81/81 passing means all *included automated cases*, not numerical code/branch coverage. No instrumentation-based coverage percentage was measured.
