Connect and test a workflow

Open the extension popup in your test browser profile. Set the WebSocket URL to and click Save and reconnect. Open a supported chat site in that profile.

  1. Run Get tab list. Choose the calling chat's tab ID and browser session in subsequent forms.
  2. In queue mode, register the manager and start delivery to test ordered reports and acknowledgments.
  3. Spawn a worker with a site and task. Use its task ID for Get result and its tab ID for Read chat or Send message. Repeat for additional workers.
  4. Inspect pending events and reports. Acknowledge a delivered batch after processing its events, then close the worker. To test recovery, close a worker in the browser and use Reopen child with its original task ID.
  5. For failure tests, enter an unknown ID or take the bridge offline. Bring it online and watch for a new session handshake.

Each log entry expands to its full payload. Commands act on real tabs in the connected browser profile.
